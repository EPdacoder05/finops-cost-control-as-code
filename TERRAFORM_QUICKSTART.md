# ⚡ Terraform Security - Quick Start (5 Minutes)

## 🚀 Deploy Maximum Security NOW

### Step 1: Navigate to Terraform
```bash
cd terraform/examples
```

### Step 2: Create Your Configuration
```bash
# Copy the example
cp aws-maximum-security.tf main.tf

# Edit organization name (REQUIRED)
nano main.tf  # Change 'your-organization' to YOUR organization name
```

### Step 3: Deploy
```bash
# Initialize
terraform init

# Review what will be created
terraform plan

# Deploy (type 'yes' when prompted)
terraform apply
```

**That's it!** Maximum security deployed in 5-10 minutes.
